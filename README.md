Yono PC Keyboard

Yono PC Keyboard is an advanced Android keyboard designed to bring a desktop-style typing experience to Android devices. It combines familiar PC keyboard functionality with modern mobile keyboard features, customization, productivity tools, and an optional floating keyboard mode.

The project aims to provide users with more control over their typing experience while keeping useful tools accessible directly from the keyboard.

✨ Features

🖥️ PC-Style Keyboard

- Desktop-inspired keyboard layout.
- Dedicated function and control keys.
- Comfortable typing experience for extended text input.
- Designed for users who prefer a PC-like keyboard on Android.

⌨️ Multiple Keyboard Modes

- Standard Keyboard: A full-width keyboard that stays docked at the bottom of the screen.
- Floating Keyboard: An independently resizable and movable keyboard.
- Move the floating keyboard around the screen.
- Minimize it into a floating bubble and restore it when needed.
- Customize the size of each keyboard mode independently.

🌐 Language Support

- Arabic and English keyboard layouts.
- Switch between supported languages.
- Language-aware keyboard interface.
- Translation between Arabic and English.

🔤 Translation

- Translate text between Arabic and English.
- Translation is started only when requested by the user.
- Preview translated text before inserting it.
- Apply the translation directly to the active text field using the Apply button.

📋 Smart Clipboard

- Access previously copied text from the keyboard toolbar.
- Keep important clipboard entries pinned.
- Manage and delete saved clipboard entries.
- Store clipboard history locally on the device.

💡 Smart Suggestions

- Context-aware typing suggestions.
- Suggestions based on copied text and learned phrases.
- Tools for applying useful suggestions while typing.

🎙️ Voice Input

- Voice input through the device microphone.
- Microphone permission is required when using voice input.

⚙️ Customization

- Adjust keyboard dimensions.
- Configure standard and floating keyboard modes independently.
- Save keyboard preferences and customizations locally.
- Customize the typing experience to suit your needs.

📱 Requirements

Requirement| Details
Device| Android phone or tablet
Installation| Yono PC Keyboard APK
Shizuku| Required
Root| Not required
Internet| Required for online translation and other online features

Important: You do not need Android Studio, Android SDK, Build Tools, Java, Gradle, or Termux to install and use the released APK.

Shizuku is the additional system-service requirement. No root access is required.

🚀 Installation

1. Download the latest APK from the GitHub Releases section.
2. Install the APK on your Android device.
3. Install and start Shizuku.
4. Grant the required permissions.
5. Open Android keyboard settings and enable Yono PC Keyboard.
6. Select Yono PC Keyboard as your default input method.
7. Open any text field and start using the keyboard.

🔒 Privacy

- Clipboard history is stored locally on the device.
- Translation is performed only when explicitly requested.
- The user controls when to apply translated text.
- Microphone access is used for voice input and requires permission.

🎯 Project Goal

The goal of Yono PC Keyboard is to make Android typing more flexible and productive by combining the familiarity of a desktop keyboard with the convenience of mobile features.

It is designed for users who want more control over keyboard layout, positioning, language, clipboard management, translation, and everyday typing tools.
